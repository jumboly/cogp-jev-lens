# `name` / `brand` を使う第 2 段評価
labels: design, jev, later

## なぜ検討が必要か
`name` は Lens の判断材料として最も情報量が多いが、再利用率 30%（10.7M ユニーク）でタグ単位の枠に乗らない。
`brand` は中間（65k ユニーク、上位は再利用性が高い）。

## 現在わかっていること
- 日本域では `name` 77%、`brand` 11%、`name:ja` 14%、`brand:ja` 8%
- チェーン店は同名が繰り返す（セブン-イレブン 1 万件、ファミリーマート 8 千件）
- POI 単位で名前を評価するなら、上限付き・タグ評価で絞った後、が現実的
